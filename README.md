# Bulk RNA-seq

This repository showcases analysis of bulk RNA-seq data to identify differentially expressed genes, perturbations in well-characterized biological pathways, and detection of novel biological functions through evaluation of co-expressed gene networks. These analyses were conducted in `R`.

* Differential gene expression analysis using `edgeR`.
* Gene set enrichment analysis using `GSEA` and `clusterProfiler` to evaluate enrichment in known biological pathways and gene sets.
* Weighted gene co-expression network analysis using `WGCNA` to identify new biological gene sets and novel functionality.
